# herdr.el documentation

herdr.el controls [herdr](https://herdr.dev) from Emacs. herdr is a terminal workspace manager
for AI coding agents. herdr.el puts herdr terminals in Emacs buffers.

|---|---|
| [Getting started](getting-started.md) | How to install herdr.el and do the first tasks. |
| [Commands](commands.md) | Every command, and the method that each command calls. |
| [Configuration](configuration.md) | Every user option, with the default value. |
| [Troubleshooting](troubleshooting.md) | Symptoms, causes and corrections. |
